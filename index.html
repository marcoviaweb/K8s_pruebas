Introducción

Docker es una plataforma de contenedorización que permite a los desarrolladores empaquetar aplicaciones y sus dependencias en contenedores.

Instalación

Para instalar Docker, sigue las instrucciones en la documentación oficial.

Comandos Básicos

  • docker run: Ejecuta un contenedor.
  • docker ps: Lista los contenedores en ejecución.
  • docker stop: Detiene un contenedor.

Dockerfile

Un Dockerfile es un archivo de texto que contiene las instrucciones para crear una imagen de Docker.

Docker Compose

Docker Compose es una herramienta para definir y ejecutar aplicaciones Docker con múltiples contenedores.
